# 企业版 / 私有化部署

> 一句话：代码全开源、私有化部署、数据不出你的楼，用公司自己的资料回答员工的问题。

## 适用场景

- **客服知识库**：新人三天上手，面对客户问题直接引用内部文档作答。
- **产品手册问答**：销售、售前、售后团队随时查询最新产品信息。
- **SOP / 制度查询**：员工用自然语言提问，快速定位内部流程与规章。
- **研发知识沉淀**：技术文档、方案评审、故障复盘统一可检索、可问答。
