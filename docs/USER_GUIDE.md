# 用户手册

## 产品简介

**个人第二大脑**（Personal Second Brain）是一个 AI 增强的个人知识管理系统。它采用独特的**双脑模式**：
- **个人脑（Personal Brain）**：私密的笔记、灵感、反思
- **网络脑（Network Brain）**：从网页剪藏、外部验证的知识

通过双脑融合，系统能帮你发现跨领域的隐性关联，激发创意涌现。

## 快速开始

### 1. 注册与登录
1. 打开 http://localhost:3000
2. 点击「注册」，输入邮箱和密码（密码需包含大小写字母和数字）
3. 登录后进入 Dashboard

### 2. 创建第一条笔记
1. 点击左侧菜单「采集中心」→「笔记管理」
2. 点击「新建笔记」
3. 输入标题和内容，添加标签
4. 点击保存，笔记会自动建立关联边

### 3. 使用浏览器剪藏
1. 安装浏览器扩展（Chrome 扩展管理页加载 `browser-extension/dist/`）
2. 浏览网页时点击扩展图标
3. 系统自动提取正文、元数据和可信度评分
4. 内容存入「网络脑」等待验证

## 核心功能指南

### 采集中心
- **笔记**：Markdown 编辑器，支持 AI 自动摘要和标签提取
- **剪藏**：一键保存网页，自动提取正文、作者、发布时间
- **标签系统**：为内容打上标签，支持颜色区分，建立知识分类

### 反脆弱知识库
- **知识验证**：AI 多模型交叉验证知识可信度，标记为确认/争议/证伪
- **来源追溯**：查看知识来源的 URL、作者、可信度评分、资助方
- **时效性管理**：知识会随时间衰减，系统提醒复查过时信息

### 时间胶囊
- **创建**：封存一条记忆、一个想法、一段心情，设定未来解锁条件
- **解锁条件**：到达日期、发生事件、达成里程碑
- **跨时空对话**：解锁后与过去的自己对话，AI 分析成长轨迹和变化模式

### 注意力管家
- **深度工作**：设定任务和专注时长，屏蔽干扰应用和网站
- **时间追踪**：记录时间分配，自动分类活动类型
- **专注度评分**：基于中断次数、切换频率计算专注质量
- **仪表盘**：可视化每日时间分配和专注趋势

### 认知镜像
- **思维指纹**：AI 分析你的写作风格、关注领域、思维偏好，生成画像
- **偏差检测**：识别确认偏误、锚定效应、幸存者偏差等认知偏差
- **反思建议**：基于偏差分析提供视角切换建议

### 涌现工作室
- **跨域联想**：输入两个领域，AI 生成跨界创新点子
- **创意碰撞**：输入两个概念，生成融合后的新创意
- **概念杂交**：组合多个概念特征，生成新术语和定义
- **反事实探索**：假设历史不同走向，生成平行世界叙事

### 知识图谱
- **双脑可视化**：个人脑和网络脑的知识节点与关联边
- **自动关联**：AI 自动发现内容间的隐性关联
- **路径查找**：查找两个知识点之间的最短路径
- **社群检测**：发现知识聚类，揭示兴趣领域

### 双脑融合搜索
- 同时搜索个人脑和网络脑的内容
- 按相关性排序，显示来源脑（Personal/Network）
- 支持跨脑关联跳转

## 设置与账户

### AI 配置
- 设置 → AI 配置：选择默认 LLM 模型（Ollama 本地模型）
- 设置嵌入模型：用于知识向量化和语义搜索

### 隐私
- 设置 → 隐私：选择数据加密级别（本地 AES / 服务端加密）
- 设置 → 导出：导出全部个人数据为 JSON

### 同步
- 设置 → 同步：配置自动同步间隔
- 支持离线模式，恢复网络后自动同步

## 常见问题 FAQ

1. **忘记密码怎么办？**
   联系管理员重置密码，或在登录页点击「忘记密码」（如已配置邮件服务）。

2. **笔记丢失？**
   检查是否切换了大脑（Personal/Network），检查回收站状态。

3. **剪藏失败？**
   检查网页是否为 SPA 或需要登录，可尝试手动粘贴内容。

4. **LLM 响应慢？**
   本地 Ollama 依赖硬件性能，可在设置中切换更小的模型。

5. **知识验证结果不准？**
   验证依赖 AI 判断，建议结合人工复核，特别是争议性知识。

6. **如何删除账户？**
   设置 → 账户安全 → 删除账户，需输入密码和确认文字「删除我的账户」。

7. **时间胶囊无法解锁？**
   检查解锁条件是否满足，如日期未到或事件未触发。

8. **注意力追踪不工作？**
   确保浏览器扩展已授权。

9. **知识图谱加载慢？**
   数据量大时首次加载需时间，系统使用增量渲染优化。

10. **如何邀请协作者？**
    暂不支持多人协作。

11. **浏览器扩展支持哪些浏览器？**
    Chrome、Edge、Firefox（通过 manifest v2/v3）。

12. **数据存储在哪里？**
    默认本地 SQLite，可配置 PostgreSQL 和云存储。

13. **是否支持移动端？**
    响应式设计支持手机浏览器，原生 App 开发中。

14. **如何备份数据？**
    设置 → 导出 → 下载全部数据，或手动备份 `psb.db` 文件。

15. **_capsule 的跨时空对话是什么意思？**
    解锁后，AI 扮演过去的你，与现在的你对话，分析思维变化和成长。
