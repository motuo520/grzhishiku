# 与同类工具对比

| 能力 | 个人第二大脑 | Obsidian | ima.copilot |
|------|-------------|----------|-------------|
| 本地模型免费跑 | ✅ Ollama | 需插件 | ❌ |
| RAG 引用原文 | ✅ | 需插件 | 部分支持 |
| 网页剪藏 | ✅ | 需插件 | ✅ |
| 数据完全本地 | ✅ 默认 | ✅ | ❌ |
| 服务端开源 | ✅ AGPL-3.0 | 客户端闭源 | 闭源 |
| 多模型路由 | ✅ | 插件实现 | 部分 |
| 自托管成本 | 低 | 仅客户端 | 依赖官方 |

## 适用场景

- **个人第二大脑**：希望数据本地优先、可自托管、需要多模型自由切换的技术用户。
- **Obsidian**：偏好纯本地 Markdown 编辑、已有丰富插件生态的用户。
- **ima.copilot**：希望开箱即用、不介意云端托管的用户。
