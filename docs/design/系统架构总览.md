## 1. 项目概述

### 1.1 核心定位

**Personal Second Brain** 是一个本地优先、AI 增强的个人知识管理系统。它将用户自身产生的数据（个人脑）与从互联网采集的数据（网络脑）彻底分离，同时提供完整的 SaaS 运营后台。

### 1.2 双脑理念

| 维度 | 个人脑（Personal Brain） | 网络脑（Network Brain） |
|------|------------------------|------------------------|
| **数据归属** | 用户自己产生 | 外部互联网采集 |
| **隐私级别** | 🔴 最高（敏感，不离开本地） | 🟡 中等（公开互联网内容） |
| **默认 LLM** | 本地模型（Ollama） | 外部模型（OpenAI/Claude/Kimi/千问） |
| **视觉标识** | 暖色调（琥珀色 `#d29922`） | 冷色调（蓝色 `#58a6ff`） |
| **核心操作** | 创作、思考、记忆、决策、情感 | 采集、阅读、研究、追踪、验证 |
| **导出策略** | 完全导出，无限制 | 可导出，保留来源链 |

### 1.3 功能模块总览（8 大主菜单）

```
📥 采集（Ingestion）          ← 网络脑：剪藏、RSS、邮件、社交、LLM集成
🔗 图谱（Graph）              ← 双脑：知识网络、全局搜索、双向链接
🧬 认知镜像（Cognitive Mirror） ← 个人脑：思维指纹、认知偏差、决策审计、未来模拟
💡 涌现工作室（Emergence Studio） ← 双脑：跨域联想、创意碰撞、概念杂交、反事实探索
🎯 注意力管家（Attention）    ← 个人脑：投资组合、深度工作、模式分析
⏳ 时间胶囊（Time Capsule）    ← 个人脑：封存、解锁、跨时空对话
🛡️ 反脆弱知识库（Anti-Fragile） ← 网络脑：来源追溯、多模型验证、时效追踪、反证收集
⚙️ 设置（Settings）           ← 系统：账户、隐私、AI、同步、插件、数据、外观
```

### 1.4 管理员后台（Admin Dashboard）

面向平台运营人员，提供：用户管理、内容审核、数据统计、订阅计费、系统管理、日志审计、客服工单。

-- ==================== 全文搜索虚拟表 ====================
CREATE VIRTUAL TABLE knowledge_fts USING fts5(
    content_raw,
    content='knowledge_units',
    content_rowid='rowid'
);

-- FTS5 同步触发器
CREATE TRIGGER knowledge_fts_insert AFTER INSERT ON knowledge_units BEGIN
    INSERT INTO knowledge_fts(rowid, content_raw) VALUES (new.rowid, new.content_raw);
END;
CREATE TRIGGER knowledge_fts_update AFTER UPDATE ON knowledge_units BEGIN
    UPDATE knowledge_fts SET content_raw = new.content_raw WHERE rowid = new.rowid;
END;
CREATE TRIGGER knowledge_fts_delete AFTER DELETE ON knowledge_units BEGIN
    DELETE FROM knowledge_fts WHERE rowid = old.rowid;
END;

## 9. 快速启动命令

```bash
# 1. 克隆项目后，一键启动全部服务
make dev          # 启动前端 + 后端 + 插件热更新

# 2. 手动启动
# 前端
cd frontend && npm run dev

# 后端
cd backend && uvicorn app.main:app --reload --port 8000

# 插件（开发模式）
cd browser-extension && npm run dev

# 3. 构建
cd frontend && npm run build
cd backend && docker build -t psb-backend .
cd browser-extension && npm run build

# 4. 部署
docker-compose up -d

# 5. 数据库迁移
cd backend && alembic upgrade head

# 6. 初始化管理员账户
cd backend && python scripts/create_admin.py --email admin@psb.local --name "Super Admin" --role super_admin
```
